# Fun Project Challenge: Three Java Games

Welcome to the Fun Project Challenge! In this repository, you will find three simple text-based games implemented in Java. 
These games are designed to be fun projects to work on and a great way to practice your Java programming skills. 
Each game has its own unique challenge, and you can choose to work on one or all of them.

## Games Included

### 1. Guess the Number

- Description: In this game, the computer randomly selects a number within a specified range, and the player must guess the number within a limited number of attempts.
- Starter Code: Provided in the repository.
- Task Highlights:
    - Implement logic to check if the user's guess is correct.
    - Display the number of attempts remaining.
    - Add an option for the player to play again.
    - Implement input validation to handle non-integer inputs and out-of-range guesses.

### 2. Hangman

- Description: Hangman is a word-guessing game. The computer selects a random word, and the player must guess the word one letter at a time while avoiding too many incorrect guesses.
- Starter Code: Provided in the repository.
- Task Highlights:
    - Implement the game loop.
    - Display the current state of the board after each move.
    - Check for a win or a draw after each move.
    - Implement input validation to handle invalid moves.
    - Add an option for the player to play again.
    
### 3. Word Guess

- Description: Word Guess is a game where the computer selects a random word, and the player needs to guess the word one letter at a time with a limited number of incorrect guesses.
- Starter Code: Provided in the repository.
- Task Highlights:
    - Randomly select a word from a list.
    - Initialize the guessed word with underscores.
    - Get a letter guess from the player.
    - Check if the guessed letter is in the word.
    - Check if the player has guessed the entire word.
    - Display a message to indicate the game outcome.
    - Add an option for the player to play again.
